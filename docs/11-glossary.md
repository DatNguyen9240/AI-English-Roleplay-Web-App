# 11. Glossary

| Term | Meaning |
| --- | --- |
| Activity | A runnable learning unit rendered through a capability. |
| AssessmentResult | Immutable standardized result of evaluating an attempt. |
| Attempt / LearningTurn | A learner's submitted voice or text response. |
| Capability | Reusable contract such as Speaking, Reading or Writing. |
| ContentBlock | Versioned source content: text, audio, image or prompt material. |
| Decision | Explainable result with outcome, reason codes, confidence and version refs. |
| Engine | A business ownership boundary, not automatically a service. |
| Knowledge Delta | A requested change to learner knowledge after an assessment. |
| Knowledge Node | A unit of knowledge: word, grammar, skill, concept or topic. |
| LearningContext | Immutable request context with learner, locale, policy and capability refs. |
| Outbox Event | A durable event written with the transaction, published later by a worker. |
| Policy | Rules by learner segment/capability: safety, difficulty, feature flags and entitlement. |
| Recommendation | A decision about the best next learning action. |
| Replay | Re-assessing a past attempt with a newer workflow without changing old history. |
| SRS | Spaced repetition scheduling based on learner knowledge state. |
| VersionRef | Common identifier for a versioned content/rubric/prompt/policy/capability artifact. |
